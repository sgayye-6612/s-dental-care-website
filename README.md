# S Dental Care — Website

One-page website for S Dental Care and Dr. Sreeshma Sunder (Orthodontist · Invisalign Provider), Moosapet X Roads, Hyderabad.

## Files
- `index.html` — the whole website (HTML, CSS and JavaScript)
- `images/` — photos and videos used on the page

## Run locally
Open the folder in VS Code → right-click `index.html` → **Open with Live Server**.
